# Moonlighter's Pocket Rocket — Alpha

Free, offline ER and RHU orders in DILMO format for Philippine moonlighters and RHU doctors.

**Unverified alpha build. Reference only. Use at your own risk.** It does not replace clinical judgment, the product label, the PNF or local protocols. Check every dose before you give it.

## Use it
- Open https://zoltrak-web.github.io/pocket-rocket/ on your phone, then **Install** (Android Chrome) or **Share → Add to Home Screen** (iPhone Safari).
- After the first open it works offline. When a new version is ready, a banner asks you to update.
