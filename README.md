# Moonlighter's Pocket Rocket — Alpha

Offline ER and RHU orders in DILMO format for Philippine moonlighters. **Alpha test build. Use at your own risk.** Not a substitute for clinical judgment, local protocols, or the product label.

- Open the site link on your phone, then **Install** (Android Chrome) or **Share → Add to Home Screen** (iPhone Safari).
- After the first open it works offline. When a new version is ready, a banner asks you to update.
